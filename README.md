# 스마트박스 (SmartBox)

주행 중 사용하지 않는 스마트폰을 **페달·뒷좌석 보조 카메라**로 쓰고, 그 영상에 **차량 주행 데이터**를 같은 시간축으로 묶어 기록하는 차량 앱입니다.
순정 블랙박스가 보지 못하는 차 안의 사각지대를 기록합니다.

> 현대자동차그룹 차량용 앱 개발 공모전(Pleos App Market) 출품용 시제품입니다.

## 구성

```
 [스마트폰: 페달 카메라] ─┐                     ┌─ 차량 화면 (Pleos Connect / AAOS)
 [스마트폰: 뒷좌석 카메라] ┼── 같은 Wi-Fi/핫스팟 ──┤   · 차량 데이터(속도·기어·시동·페달)
        (차량 USB로 충전)  ┘                     └   · 이벤트 감지, 실시간 화면, 기록 재생
```

| 폴더 | 내용 |
|---|---|
| `vehicle/` | 차량 앱. 차량 데이터 수집, 이벤트 감지, 실시간 화면, 기록 재생, 하차 알림 |
| `phone/` | 스마트폰 카메라 앱. 화면 꺼짐 백그라운드 녹화, 충전 감지 자동 시작, 이벤트 영상 보관 |
| `core/` | 두 앱이 함께 쓰는 로직. 이벤트 감지, 시계 맞추기, 루프 녹화 관리, 움직임 감지, 통신 (단위 테스트 포함) |

## 주요 기능

1. **시동과 함께 자동 녹화**: 시동을 걸어 차량 USB 전원이 들어오면 스마트폰이 충전 시작을 감지해 녹화를 시작하고, 차량 앱의 시동 신호로 한 번 더 확인합니다. 시동을 끄면 녹화를 멈춥니다.
2. **화면 꺼짐 녹화**: 스마트폰은 화면이 꺼진 채 포그라운드 서비스로 녹화해 번인·발열·배터리 소모를 줄입니다.
3. **이벤트 자동 보관**: 급가속·급감속(속도 변화), 저속에서 가속 페달 급조작(페달 값이 제공될 때)을 감지하면, 앞뒤 20초 영상을 지워지지 않게 따로 보관합니다. "지금 기록 저장" 버튼으로 직접 저장할 수도 있습니다.
4. **영상 + 차량 데이터 동기화 재생**: 기록을 열면 영상을 재생하면서, 속도·가속 페달·브레이크 그래프에 지금 재생 중인 시각을 흰 선으로 표시합니다.
5. **뒷좌석 확인**: 정차 중에는 크게, 주행 중에는 버튼을 눌렀을 때만 작은 화면으로 5초간 보여 줍니다.
6. **하차 알림**: P단으로 바꾸거나 시동을 끌 때 뒷좌석 카메라에 움직임이 있으면 확인 알림을 띄웁니다.

## 시연 방법 (차량 없이)

준비물: 안드로이드 기기 2대 이상 (차량 화면 역할 1대 + 카메라 역할 1~2대), 같은 Wi-Fi

1. `apk/` 폴더의 APK를 설치합니다.
   - 차량 화면 역할(태블릿 권장): `smartbox-vehicle.apk`
   - 카메라 역할: `smartbox-camera.apk`
2. 차량 앱을 엽니다. 일반 기기에서는 자동으로 **시뮬레이터**로 동작하고, 화면에 QR 코드와 연결 코드가 나옵니다.
3. 카메라 앱에서 카메라 위치(페달/뒷좌석)를 고르고, **차량 화면의 QR 코드 스캔**으로 연결합니다.
4. **대기 모드 시작**을 누릅니다. 충전기를 꽂으면 녹화가 시작됩니다. 충전기 없이 보려면 **충전 없이 녹화 테스트**를 누릅니다.
5. 차량 앱에서 `시동 켜기` → `출발` → `급제동`을 누르면 이벤트가 기록됩니다.
6. 약 45초 뒤(이벤트 뒤 20초까지 녹화 + 마무리) `P단 주차` 후 기록의 **보기**를 누르면 영상과 그래프가 함께 재생됩니다.
7. 뒷좌석 카메라 앞에서 손을 움직인 채 `P단 주차`를 누르면 하차 알림이 뜹니다.

Android Automotive 에뮬레이터나 실제 AAOS 기기에서는 시뮬레이터 대신 **Car API의 실제 차량 데이터**를 사용합니다(스위치로 시뮬레이터 전환 가능).

## 빌드

```bash
./gradlew :core:test          # 공용 로직 단위 테스트
./gradlew assembleRelease     # APK 빌드 (시제품이라 디버그 키로 서명)
```

요구 사항: JDK 17 이상, Android SDK 35, minSdk 28 (Android 9)

## 기술 메모

- **차량 데이터**: `vehicle/.../VehicleSource.kt`. 현재는 Android Automotive 표준 Car API(`PERF_VEHICLE_SPEED`, `GEAR_SELECTION`, `IGNITION_STATE`, 가능한 경우 페달 값)와 시뮬레이터를 지원합니다. Pleos Vehicle SDK는 같은 `VehicleSource` 인터페이스를 구현해 추가할 예정입니다. 페달 신호를 쓸 수 없는 차종에서는 속도 변화로 급가속·급감속을 판단합니다.
- **통신**: 외부 서버 없이 같은 로컬 네트워크에서 작은 HTTP 서버로 통신합니다(`core/.../Protocol.kt`). 모든 요청은 차량 화면의 6자리 연결 코드로 확인합니다.
- **시간 맞추기**: 스마트폰이 차량 시각을 여러 번 물어 왕복 시간이 가장 짧은 측정값으로 시계 차이를 보정합니다(`ClockSync`). 그래서 영상 프레임과 차량 데이터가 같은 시간축에 놓입니다.
- **루프 녹화**: 20초 조각으로 녹화하고 저장 한도(1GB)를 넘으면 오래된 조각부터 지웁니다. 이벤트 구간과 겹치는 조각은 보호했다가 `events/` 폴더로 복사합니다(`SegmentStore`).
- **안드로이드 백그라운드 카메라 제한**: 백그라운드에서 갑자기 카메라를 켤 수 없기 때문에, 사용자가 앱을 열어 대기 모드를 켤 때 카메라 유형의 포그라운드 서비스를 시작해 두고, 이후 충전·시동 신호에 따라 녹화만 켜고 끕니다.

## 안전·개인정보 설계

1. 주행 중에는 영상을 숨기고, 뒷좌석 확인은 버튼을 누를 때만 작은 화면으로 5초 동안 보여 줍니다. 기록 영상은 정차 중에만 재생됩니다.
2. 촬영 범위는 페달과 뒷좌석으로 한정하고, **음성은 녹음하지 않습니다**(마이크 권한을 요청하지 않음).
3. 녹화 중에는 차량 화면 상단에 녹화 표시를 항상 띄워 탑승자가 알 수 있게 합니다.
4. 영상은 사용자의 스마트폰에만 저장되며 외부 서버로 보내지 않습니다.

## 현재 한계와 다음 단계

- 실제 차량과 Pleos Connect 환경에서의 검증이 필요합니다. 현재는 빌드·단위 테스트까지 확인했습니다.
- Pleos Vehicle SDK, FusedLocation SDK, NaviHelper SDK 연동(위치 기록, 도착 시점 하차 알림)은 SDK 접근 후 추가합니다.
- 차량 앱의 기록 목록은 앱을 다시 시작하면 사라집니다(영상은 스마트폰에 남음). 목록 저장 기능을 추가할 예정입니다.
- 일부 제조사 기기는 배터리 절약 기능이 대기 중인 앱을 종료할 수 있어, 카메라 앱의 "배터리 최적화 제외 설정"을 켜야 합니다.
- 장시간 충전과 녹화를 함께 하면 발열이 생길 수 있어, 차량 화면에 휴대폰 온도를 표시합니다. 화질 자동 조절은 다음 단계입니다.
